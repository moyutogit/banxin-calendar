# 隐私说明（V1.0）

班薪日历默认不要求账号，排班、考勤、工资、闹钟、AI 对话、智能体画像与记忆和备份保存在用户
设备上。应用不集成广告、跨应用追踪或第三方崩溃分析 SDK。

## AI 数据出站

AI 助理为可选功能。只有用户自行配置 HTTPS 模型接口并主动发送消息时，应用才会
把对话和已授权的最小范围摘要发送到用户选择的服务商。智能体记忆只有在用户明确要求“记住”时才写入本地数据库，
并且只有在记忆权限开启、模型主动调用记忆工具时才会作为最小范围摘要发送。工资金额和备注读取默认关闭；
关闭的数据范围不会进入请求。服务商如何处理数据由其隐私条款决定。

API 密钥和敏感自定义请求头仅保存在 iOS Keychain / Android Keystore 支持的系统
安全存储中，不写入 SQLite、日志、CSV 或普通备份。更换 API 域名必须再次确认。

## 本地权限

- 网络：仅用于用户主动更新节假日数据和调用自行配置的 AI 接口。
- 通知/精确闹钟：仅在用户主动开启闹钟时申请；Android 用于排班精确提醒，iOS
  使用本地通知。
- 开机广播（Android）：只用于恢复本应用管理的未来闹钟。

应用不读取或修改系统“时钟”App 中已有闹钟。

## 备份与删除

普通备份会排除安全凭据，包含 schema/App 版本、创建时间、数据范围和 SHA-256
校验。恢复前会先备份当前数据，在临时数据库迁移和校验后以单事务替换，并重建缓存
和闹钟。设置页提供清除对话、AI 操作历史、模型配置与安全凭据、工资与考勤、全部
App 数据的独立入口，每项均需二次确认。
